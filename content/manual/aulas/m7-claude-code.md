Esta é a etapa final. Antes de começar, confira se a pasta do projeto tem os três arquivos:

- o **vídeo original** de referência;
- o **roteiro** adaptado;
- o **áudio** narrado.

## Passo a passo

1. Abra o **Claude Code** e inicie uma **nova conversa**.
2. Informe o **caminho completo da pasta** do projeto no seu computador.
3. Explique que dentro dela estão o vídeo original de referência, o roteiro e o áudio pronto.
4. Peça para o Claude Code usar esses materiais para criar o vídeo.

## Prompt de exemplo

Copie, troque o caminho e os nomes dos arquivos pelos seus e envie:

```
A pasta do meu projeto é: C:\perfil-1\semana-01\video-01

Dentro dela estão:
- original.mp4: o vídeo de referência
- roteiro.txt: o roteiro adaptado
- audio.mp3: a narração pronta

Use esses materiais para criar o vídeo final, seguindo o estilo e o ritmo do vídeo de referência e usando o meu áudio como narração.
```
