O método usa uma ferramenta obrigatória e duas opcionais.

## Obrigatória

### Claude Code

É a ferramenta principal: é com ele que você cria o vídeo final, a partir do roteiro, do áudio e do vídeo de referência. O Claude Code roda no computador (Windows, macOS ou Linux), então você vai precisar de um computador para essa etapa.

- [Página oficial do Claude Code](https://claude.com/product/claude-code)
- [Planos e assinatura](https://claude.com/pricing)
- [Como instalar (guia oficial em português)](https://code.claude.com/docs/pt/overview)

## Opcionais

### ChatGPT

Apoio para analisar, traduzir, adaptar ou criar roteiros a partir da transcrição. Se preferir, você pode usar outra inteligência artificial.

### ElevenLabs

Gera a narração com inteligência artificial a partir do roteiro. Se preferir gravar com a sua própria voz, você não precisa do ElevenLabs.

## O que você precisa para começar

- Um computador para usar o Claude Code.
- Acesso ao Claude Code.
- Uma conta no ChatGPT (ou outra IA) para trabalhar o roteiro, se quiser usar.
- Uma conta no ElevenLabs, se não for narrar com a sua voz.

> Essas ferramentas são de terceiros e podem ter custos próprios, que não estão incluídos no valor do manual.
